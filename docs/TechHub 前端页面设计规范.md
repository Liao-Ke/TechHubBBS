## 1. 设计理念与视觉方向

### 1.1 核心定位

**"Developer Elegance"（开发者优雅）**—— 为技术社区打造的视觉语言，融合编辑器的精准与现代文档站的可读性。

| 维度 | 方向 |
|------|------|
| **整体调性** | 干净、专业、可信赖，同时保有技术社区的活力与温度 |
| **差异化记忆点** | 暗色模式优先（非事后追加），代码区块的终端质感，细线几何分割 |
| **类比参考** | GitHub 的克制 + 现代文档站的可读性 + 终端的美学性格 |
| **反模式（禁止）** | 紫色渐变、Roboto 字体、卡片悬浮阴影过重、霓虹 glow 效果 |

### 1.2 设计原则

1. **内容优先** —— 帖子正文是核心，UI 元素应为背景，不可喧宾夺主。大段文字排版必须有极佳可读性。
2. **状态透明** —— 每个页面需明确呈现四种状态：加载中（骨架屏）、正常、空数据（引导文案）、错误（重试入口）。
3. **权限可视** —— 用户应能直观感知自己当前的角色与可用操作。不可见的功能区域应优雅隐藏（而非灰化禁用）。
4. **动效克制** —— 过渡动画用于建立空间关系与反馈确认，不用于炫技。时长默认 200-300ms。
5. **暗色优先** —— 设计决策优先在暗色背景下验证，再适配亮色。

### 1.3 四大页面类型的视觉侧重点

| 页面类型 | 视觉重心 | 代表页面 |
|----------|----------|----------|
| **内容消费** | 排版可读性、信息层级、沉浸感 | 帖子详情页、版块页 |
| **内容创作** | 编辑器体验、工具栏可达性、预览区真实感 | 发帖/编辑页 |
| **数据管理** | 信息密度、操作效率、状态标识清晰 | 管理后台各页面 |
| **身份认证** | 品牌传达、安全感、简洁高效 | 登录/注册页 |

## 2. 色彩系统

### 2.1 设计理念

基于 Element Plus 的 CSS 变量体系，通过覆盖 `--el-*` 变量实现全局主题。色彩方案围绕**深海军蓝主色**构建，传达技术感与专业性。

### 2.2 主题色板（暗色模式 / 默认）

这是**主要色彩方案**——暗色模式为默认体验，亮色模式作为辅助选项。

| `--el-color-primary` | `#58a6ff` | 主操作按钮、链接、选中态、品牌标识 |

## 3. 字体排版

### 3.1 字体家族

| 用途 | 字体栈 | 权重范围 |
|------|--------|----------|
| **UI / 正文** | `Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Noto Sans SC', sans-serif` | 400, 500, 600, 700 |
| **代码 / 编辑器** | `'JetBrains Mono', 'Cascadia Code', 'Fira Code', 'Consolas', monospace` | 400, 500 |
| **特殊数字 / 统计** | `'Inter', -apple-system, sans-serif` | 600, 700 (tabular-nums) |

> **注意**: 不使用 `Inter` 以外的 Google Font。`Inter` 通过 `@fontsource/inter`（npm 包）本地化引入，避免外部 CDN 依赖。中文字体回退至 `Noto Sans SC`（系统自带）。

### 3.2 字号与行高等级

| 等级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| **H1** | 28px | 1.3 | 700 | 页面主标题（帖子标题） |
| **H2** | 22px | 1.35 | 600 | 区块标题（神评专区、相关帖子） |
| **H3** | 18px | 1.4 | 600 | 卡片标题、面板标题 |
| **H4** | 16px | 1.45 | 600 | 小标题、表单标签 |
| **Body L** | 16px | 1.6 | 400 | 帖子正文、长文本 |
| **Body M** | 14px | 1.5 | 400 | 列表项、回复内容、表单内容 |
| **Body S** | 13px | 1.45 | 400 | 辅助信息、时间戳、元数据 |
| **Caption** | 12px | 1.4 | 400 | 标签文字、小徽标 |
| **Code** | 13px | 1.55 | 400 | 代码块、行内代码 |

### 3.3 Markdown 内容排版

}

## 4. 间距与布局网格

### 4.1 基准间距

采用 **4px 基准栅格**，所有间距为 4 的整数倍。

| Token | 值 | 场景 |
|-------|-----|------|
| `--th-spacing-xs` | 4px | 图标与文字间距、紧密排列元素 |
| `--th-spacing-sm` | 8px | 表单内间距、标签间距 |
| `--th-spacing-md` | 16px | 卡片内边距、列表项间距 |
| `--th-spacing-lg` | 24px | 区块间距、页面内容区 padding |
| `--th-spacing-xl` | 32px | 大区块分隔、页脚间距 |
| `--th-spacing-2xl` | 48px | 页面顶部间距、hero 区域 |
| `--th-spacing-3xl` | 64px | 页面上下的呼吸空间 |

### 4.2 内容区最大宽度

| 页面类型 | 最大宽度 | 说明 |
|----------|----------|------|
| **内容消费页**（帖子详情、用户主页） | `800px` | 窄栏阅读，提升长文可读性 |
| **列表页**（首页推荐流、版块页、通知列表） | `960px` | 适中的信息密度 |
| **管理后台** | `100%` 或 `1280px` | 表格/图表需要宽度 |
| **认证页**（登录/注册） | `420px` | 紧凑表单卡片 |
| **创作页**（发帖/编辑帖子） | `960px` | 编辑器左右分栏需要空间 |

## 6. 动效规范

### 6.1 设计原则

- **使用 CSS 优先**：过渡与基础动画使用 CSS transition/animation，复杂编排使用 Vue 的 `<Transition>` 和 `<TransitionGroup>`。
- **不引入额外动效库**：禁止使用 Animate.css、GSAP、Motion One 等第三方动效库，依赖 Element Plus 内置 + CSS + Vue Transition。
- **可访问性**：尊重 `prefers-reduced-motion: reduce` 媒体查询，关闭非必要动画。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 6.2 过渡时间标准

| 类型 | 时长 | 缓动函数 | 场景 |
|------|------|----------|------|
| **微交互** | 150ms | `ease` | 按钮 hover 颜色变化、图标旋转 |
| **标准过渡** | 250ms | `ease` | 弹窗打开/关闭、面板展开/收起、路由切换淡入 |
| **强调过渡** | 400ms | `ease-out` | 页面首次加载的元素揭示、骨架屏→内容切换 |

### 6.3 具体动效定义

#### 6.3.1 路由切换

```
类型: 淡入淡出（fade）
时长: 250ms
实现: <RouterView v-slot="{ Component }">
        <Transition name="page-fade" mode="out-in">
          <component :is="Component" />
        </Transition>
      </RouterView>

.page-fade-enter-active, .page-fade-leave-active { transition: opacity 250ms ease; }
.page-fade-enter-from, .page-fade-leave-to { opacity: 0; }
```

#### 6.3.2 列表揭示（首页推荐流、通知列表）

```
类型: 依次淡入上移（staggered fade-up）
时长: 300ms / 项，间隔 50ms
实现: <TransitionGroup name="list-reveal">
        <div v-for="item in items" :key="item.id" ... />
      </TransitionGroup>

.list-reveal-enter-active { transition: all 300ms ease-out; }
.list-reveal-enter-from { opacity: 0; transform: translateY(12px); }
```

#### 6.3.3 弹窗 / 抽屉

```
类型: 缩放淡入（dialog）/ 右滑入（drawer）
时长: 250ms
实现: Element Plus 内置 <el-dialog> / <el-drawer> 动画
```

#### 6.3.4 通知铃铛

```
类型: 弹性晃动（bell swing）
触发: 新通知到达时（未读数从 0 → 1）
时长: 500ms
实现: CSS @keyframes bellSwing {
  0%, 100% { transform: rotate(0); }
  15% { transform: rotate(15deg); }
  30% { transform: rotate(-15deg); }
  45% { transform: rotate(10deg); }
  60% { transform: rotate(-10deg); }
  75% { transform: rotate(5deg); }
}
```

#### 6.3.5 骨架屏→内容

```
类型: 骨架屏淡出 + 内容淡入（crossfade）
时长: 骨架屏 200ms 淡出 → 内容 200ms 淡入
实现: v-if 切换 + fade transition
```

#### 6.3.6 点赞 / 收藏按钮

```
类型: 点击时 scale(1.2) + 颜色过渡，弹回 scale(1)
时长: 200ms
实现: .like-btn:active { transform: scale(1.2); transition: transform 150ms ease; }
```

#### 6.3.7 AI 面板内容流式输出

```
类型: 内容区域缓慢展开 + 文字渐显
时长: 面板高度 transition 400ms，文字 opacity 250ms
实现: <Transition name="ai-expand">
.ai-expand-enter-active { transition: all 400ms ease-out; }
.ai-expand-enter-from { opacity: 0; max-height: 0; }
```

## 11. 暗色模式规范

### 11.1 实现方式

使用 Element Plus 内置暗色模式 + CSS 变量覆盖：

```typescript
// main.ts
import 'element-plus/theme-chalk/dark/css-vars.css'
```

```scss
// src/assets/styles/dark-mode.scss
html.dark {
  // 自定义暗色变量（见第 2.2 节色板）
  --el-bg-color: #0d1117;
  --el-bg-color-overlay: #161b22;
  // ... 其他变量覆盖
}
```

### 11.2 暗色模式下的特殊处理

| 元素 | 暗色模式规范 |
|------|-------------|
| **代码块** | 背景使用 `#0d1117`（略深于卡片背景），与 GitHub 暗色风格一致 |
| **神评卡片** | 金色边框改为 `rgba(210, 153, 34, 0.3)`，背景 `rgba(210, 153, 34, 0.06)` |
| **AI 面板** | 蓝色边框改为 `rgba(88, 166, 255, 0.2)`，背景 `rgba(88, 166, 255, 0.05)` |
| **图片** | 在图片周围添加白色 10% 透明边框，防止暗色图片融入背景 |
| **阴影** | 使用纯黑阴影（`rgba(0,0,0,0.5)` 等），不用彩色阴影 |
| **边框** | 所有边框更细更暗（`#30363d`），分割感更柔和 |

### 11.3 模式切换

在 AppHeader 用户菜单或页面底部提供亮/暗切换按钮（月亮/太阳图标）。
默认跟随系统设置 (`prefers-color-scheme`)，用户可以手动覆盖。

## 12. 可访问性规范

### 12.1 色彩对比度

| 元素 | 要求 | 实现 |
|------|------|------|
| 正文文字 | WCAG AA (≥4.5:1) | 暗色: `#e6edf3` vs `#0d1117` = 13.8:1 ✅ |
| 大号文字（≥18px 或 ≥14px 加粗） | WCAG AA (≥3:1) | 标题自动满足 ✅ |
| 次要文字 | 尽可能满足 ≥4.5:1 | 仅时间戳等使用 `--el-text-color-secondary` |
| 交互元素 | ≥3:1 | 按钮/链接使用 `--el-color-primary`（暗色下 4.3:1 ✅） |

### 12.2 键盘导航

- 所有交互元素支持 Tab 键聚焦（`:focus-visible` 样式 = 2px 主色轮廓 + 2px 偏移）
- 弹窗打开时焦点移入，关闭时焦点返回触发元素
- 下拉菜单支持方向键导航
- Markdown 编辑器支持 Tab 缩进（不跳出编辑区）

### 12.3 屏幕阅读器

- 所有图标添加 `aria-label` 或 `aria-hidden="true"` + 相邻文字
- 通知未读数使用 `aria-label="3 条未读通知"`
- 页面标题动态更新 (`document.title`)
- 路由切换后焦点移至页面主内容区 (`<main>` 元素)

### 12.4 减少动画

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```
