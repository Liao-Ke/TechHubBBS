## 1. 概述

### 1.1 版本信息

当前 API 版本：**v1**

### 1.2 Base URL

```
/api/v1
```

### 1.3 统一响应格式

所有接口均返回以下 JSON 结构：

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 业务状态码，与 HTTP 状态码保持一致 |
| message | string | 状态描述信息 |
| data | object / array / null | 响应数据，具体结构由各接口定义 |

### 1.4 认证方式

采用 JWT（JSON Web Token）无状态认证。客户端需在请求头中携带 Token：

```
Authorization: Bearer <token>
```

Token 由登录接口签发，过期时间默认 24 小时。除明确标注"无需登录"的接口外，所有接口均需携带有效 Token。

### 1.5 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或 Token 已过期 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如重复操作） |
| 422 | 内容过短（AI 相关） |
| 500 | 服务器内部错误 |
| 503 | AI 服务暂时不可用 |

### 1.6 通用约定

**ID 类型与序列化**

所有 ID 均采用 Snowflake 算法生成，数据库存储类型为 BIGINT。在 JSON 响应中，ID 字段统一以 String 类型序列化，避免 JavaScript Number 精度丢失。

**分页**

需要分页的列表接口统一使用以下查询参数：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，从 1 开始，默认 1 |
| size | int | 否 | 每页条数，默认 10 或 20（具体参见各接口） |

分页响应结构：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 100,
    "size": 10,
    "current": 1,
    "pages": 10
  }
}
```

**排序**

列表接口通过 `sort` 参数控制排序方式：

| 值 | 说明 |
|----|------|
| new | 按创建时间倒序，置顶帖子优先展示（默认） |
| hot | 按点赞数倒序 |

**日期格式**

所有日期时间字段使用 `yyyy-MM-dd HH:mm:ss` 格式，时区为 Asia/Shanghai（UTC+8）。

**Markdown 内容**

帖子、评论等用户生成内容以原始 Markdown 文本存储。前端渲染时必须使用 DOMPurify 或同类工具进行 XSS 过滤，确保安全输出。

**文件上传**

用户头像和帖子内嵌图片通过 `POST /api/v1/files/upload` 上传。仅支持 JPG / PNG / GIF / WebP 格式，单文件上限 5MB。详见 [文件上传接口](#13-文件上传接口)。

## 2. 认证接口

### POST /api/v1/auth/register

**描述**：创建新用户账号。用户名和邮箱全局唯一。

**认证**：无需登录。

**请求参数**：

| 参数名 | 类型 | 必填 | 位置 | 说明 |
|--------|------|------|------|------|
| username | string | 是 | body | 用户名，3-50 字符 |
| password | string | 是 | body | 密码，6-100 字符 |
| email | string | 是 | body | 邮箱，需符合邮箱格式 |

**请求示例**：

```json
{
  "username": "demo_user",
  "password": "123456",
  "email": "demo@example.com"
}
```

**成功响应**：

```json
{
  "code": 200,
  "message": "注册成功",
  "data": null
}
```

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数校验失败（字段缺失、格式不合法或长度不符合要求） |
| 409 | 用户名已存在 |
| 409 | 邮箱已被注册 |

---

### POST /api/v1/auth/login

**描述**：验证用户凭据，返回 JWT Token 及基本用户信息。

**认证**：无需登录。

**请求参数**：

| 参数名 | 类型 | 必填 | 位置 | 说明 |
|--------|------|------|------|------|
| username | string | 是 | body | 用户名 |
| password | string | 是 | body | 密码 |

**请求示例**：

```json
{
  "username": "demo_user",
  "password": "123456"
}
```

**成功响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "tokenType": "Bearer",
    "userId": "1234567890123456789",
    "username": "demo_user",
    "role": "USER"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| token | string | JWT 令牌，后续请求通过 Authorization 头携带 |
| tokenType | string | 令牌类型，固定为 "Bearer" |
| userId | string | 用户 ID（String 类型） |
| username | string | 用户名 |
| role | string | 用户角色：USER / MODERATOR / ADMIN |

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 401 | 用户名或密码错误 |
| 403 | 账号已被封禁 |

### GET /api/v1/users/{id}/posts

**描述**：获取指定用户发布的帖子列表（可见性过滤）。

**认证**：无需登录（登录用户的可见性过滤放宽）。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | string | 是 | 用户 ID |

**查询参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 10 |
| sort | string | 否 | 排序：`new`（默认）/ `hot` |

**成功响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [
      {
        "id": "9876543210987654321",
        "title": "Spring Boot 3 新特性详解",
        "content": "本文梳理了 Spring Boot 3 的主要更新...",
        "categoryId": "1111111111111111111",
        "authorId": "1234567890123456789",
        "type": 0,
        "visibility": 0,
        "viewCount": 128,
        "likeCount": 32,
        "commentCount": 8,
        "divineCommentCount": 2,
        "createTime": "2026-05-20 14:22:00"
      }
    ],
    "total": 7,
    "size": 10,
    "current": 1,
    "pages": 1
  }
}
```

**业务逻辑**：未登录用户仅看到 `visibility=0` 的帖子；已登录用户额外看到有权查看的帖子。`sort=hot` 时按 `likeCount` 降序排列。

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 404 | 用户不存在 |


**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 400 | 不能关注自己 |
| 401 | 未登录 |
| 404 | 用户不存在 |

## 5. 版块公告接口

### GET /api/v1/categories/{categoryId}/notices

**描述**：获取指定版块的公告列表。置顶公告优先展示，其余按发布时间倒序。

**认证**：无需登录。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| categoryId | string | 是 | 版块 ID |

**查询参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | int | 否 | 公告类型：0=须知，1=活动。不传则返回全部 |

**成功响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": "3333333333333333333",
      "categoryId": "1111111111111111111",
      "title": "发帖须知：请遵守社区规范",
      "content": "## 基本规则\n1. 尊重他人...",
      "type": 0,
      "authorId": "1000000000000000001",
      "isPinned": 1,
      "status": 1,
      "createTime": "2026-05-01 08:00:00",
      "updateTime": "2026-05-20 10:00:00"
    }
  ]
}
```

**业务逻辑**：排序优先 `isPinned=1`，同组内按 `createTime` 倒序。

**成功响应**：

```json

  "message": "success",

    "authorId": "1234567890123456789",
```

**业务逻辑**：版主仅能在自己管辖的版块发布公告，管理员无此限制。

**错误响应**：

| 状态码 | 说明 |

## 7. 回复与神评接口

### 7.1 神评机制说明

神评是将高质量评论提升至帖子醒目位置的社区治理机制。

**入选门槛**：

| 条件 | 说明 |
|------|------|
| 帖子资格 | 帖子评论数 ≥ 10（`eligible_for_divine = 1`） |
| 评论门槛 | 点赞数 ≥ 10 **且** 推荐数 ≥ 5（双维度同时满足） |
| 反作弊 | 用户注册 ≥ 7 天方可推荐；同一用户对同一评论仅可推荐一次 |
| 动态撤销 | 低于阈值后由定时任务自动取消神评 |
| 管理员权限 | 管理员可强制设置或撤销任意评论的神评状态 |

## 10. 推荐接口

推荐系统整合基于内容的推荐和协同过滤两种策略。用户画像根据互动历史（浏览、点赞、收藏、评论）定期更新，帖子相似度矩阵通过关键词 TF-IDF 计算得出。结果经可见性过滤，并在 Redis 中缓存。个性化数据不足时自动降级为热门帖子排行。

---

### GET /api/v1/recommendations

**描述**：个性化推荐（"猜你喜欢"）。

**认证**：需要登录。

**查询参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 10 |

**业务逻辑**：
1. 从 Redis 读取用户画像缓存
2. 未命中则根据互动记录构建临时画像
3. 画像与帖子相似度矩阵匹配
4. 过滤不可见帖子
5. 分页返回

**成功响应**：分页 PostVO 列表。

---

### GET /api/v1/posts/{id}/related

**描述**：相关帖子推荐（基于相似度矩阵）。

**认证**：无需登录（过滤不可见帖子）。

**查询参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 5 |

**业务逻辑**：返回 Top-N 相似帖子，排除自身，过滤不可见。

## 11. AI 辅助接口

AI 辅助功能为每个用户提供独立的帖子摘要和问答服务。数据以用户为单位隔离存储，管理员无权查看用户 AI 数据。必须先成功生成摘要才能提问。内容过短（< 50 字符）禁止生成。问答上下文限定于原帖内容，无关问题统一回复"请基于帖子内容提问"。异步生成，通过 status 追踪：0=生成中，1=成功，2=失败。

---

### POST /api/v1/posts/{postId}/ai/summary

**描述**：生成或刷新 AI 总结（私有数据）。

**认证**：需要登录。

**请求参数**：无（无需请求体）。

**业务逻辑**：
1. 校验帖子内容长度 ≥ 50 字符
2. Upsert `ai_summary` 记录，`status=0`
3. 异步调用 LLM
4. 接口立即返回

**成功响应（创建/刷新）**：

```json
{
  "code": 200,
  "message": "生成中",
  "data": {
    "id": "8888888888888888888",
    "userId": "1234567890123456789",
    "postId": "9876543210987654321",
    "content": null,
    "status": 0,
    "createTime": "2026-05-25 09:15:00",
    "updateTime": "2026-05-25 09:15:00"
  }
}
```

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 401 | 未登录 |
| 404 | 帖子不存在 |
| 422 | 内容过短（< 50 字符），无法生成 |

---

### GET /api/v1/posts/{postId}/ai/summary

**描述**：获取自己的 AI 总结（私有数据）。

**认证**：需要登录。

**业务逻辑**：
- `status=1` → 返回内容
- `status=0` → 返回"生成中"
- `status=2` → 返回 503 错误
- 无记录 → 404

**成功响应（status=1）**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": "8888888888888888888",
    "userId": "1234567890123456789",
    "postId": "9876543210987654321",
    "content": "本文详细介绍了 Spring Boot 3.0 的主要新特性，包括原生编译支持、可观测性改进以及 Jakarta EE 迁移指南...",
    "status": 1,
    "createTime": "2026-05-25 09:15:00",
    "updateTime": "2026-05-25 09:15:30"
  }
}
```

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 401 | 未登录 |
| 404 | 未生成摘要 |
| 503 | 生成失败 |

---

### POST /api/v1/posts/{postId}/ai/qa

**描述**：对帖子内容提问。

**认证**：需要登录。

**请求参数**：

| 参数名 | 类型 | 必填 | 位置 | 说明 |
|--------|------|------|------|------|
| question | string | 是 | body | 问题内容 |

**请求示例**：

```json
{
  "question": "这篇文章提到的原生编译支持对现有项目有什么影响？"
}
```

**业务逻辑**：
1. 校验已有 `status=1` 的摘要
2. 帖子原文 + 问题 → Prompt → LLM
3. 无关问题返回"请基于帖子内容提问"
4. 问答记录存入 `ai_qa_history`

**成功响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": "9999999999999999999",
    "userId": "1234567890123456789",
    "postId": "9876543210987654321",
    "question": "这篇文章提到的原生编译支持对现有项目有什么影响？",
    "answer": "原生编译支持主要通过 GraalVM 实现...",
    "createTime": "2026-05-25 09:20:00"
  }
}
```

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 401 | 未登录 |
| 403 | 请先生成 AI 摘要 |
| 404 | 帖子不存在 |

---

### GET /api/v1/posts/{postId}/ai/qa/history

**描述**：问答历史（私有数据）。

**认证**：需要登录。

**成功响应**：问答记录数组，按 `createTime` 倒序。

## 13. 文件上传接口

### POST /api/v1/files/upload

**描述**：上传文件，支持头像和帖子内嵌图片。

**认证**：需要登录。

**请求头**：

| 头部 | 值 |
|------|-----|
| Content-Type | multipart/form-data |

**请求参数**：

| 参数名 | 类型 | 必填 | 位置 | 说明 |
|--------|------|------|------|------|
| file | MultipartFile | 是 | form | 上传的文件，仅支持 JPG / PNG / GIF / WebP，大小不超过 5MB |
| objectType | string | 否 | form | 上传类型：`user_avatar`（头像）/ `post_image`（帖子图片），默认 `post_image` |

**成功响应**：

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "url": "http://localhost:8080/file/uploads/abc123.png",
    "filename": "abc123.png",
    "size": 102400
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| url | string | 文件访问 URL，格式为 `http://host:port/file/...` |
| filename | string | 文件名 |
| size | long | 文件大小（字节） |

**业务逻辑**：

1. 校验文件大小不超过 5MB
2. 校验文件类型为 JPG / PNG / GIF / WebP
3. 根据 `type` 参数存储至不同子目录（`type=avatar` 存入 `avatar/`，`type=post` 存入 `uploads/`）
4. 依赖 dromara/x-file-storage 库，文件存储于本地文件系统 `/data/uploads/` 目录
5. 文件访问 URL 由 `application.yml` 中的 `domain` 配置拼接生成

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 400 | 文件大小超过限制（5MB） |
| 400 | 不支持的文件类型（仅允许 JPG / PNG / GIF / WebP） |
| 401 | 未登录或 Token 已过期 |

## 14. 附录

### A. 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 业务状态码，200 表示成功 |
| message | string | 状态描述信息 |
| data | object / null | 响应数据，写入类操作可为 null |

### B. 分页响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [ ... ],
    "total": 100,
    "size": 10,
    "current": 1,
    "pages": 10
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| records | array | 当前页数据列表 |
| total | int | 总记录数 |
| size | int | 每页条数 |
| current | int | 当前页码 |
| pages | int | 总页数 |

### C. 认证方式

所有需要认证的接口需在请求头中携带 Token：

```
Authorization: Bearer <token>
```

Token 通过 `POST /api/v1/auth/login` 获取，默认有效期 24 小时。被封禁用户的 Token 立即失效。

### D. 错误码总览

| 状态码 | 含义 | 使用场景 |
|--------|------|----------|
| 200 | 成功 | 请求正常处理 |
| 400 | 请求参数错误 | 参数校验失败、格式错误 |
| 401 | 未登录 | Token 缺失、过期或无效 |
| 403 | 无权限 | 角色权限不足或账号被封禁 |
| 404 | 资源不存在 | 帖子、评论、用户等不存在 |
| 409 | 冲突 | 重复操作（如重复点赞） |
| 422 | 业务逻辑错误 | 内容过短（AI 相关） |
| 500 | 服务器内部错误 | 未预期的服务端异常 |
| 503 | 服务不可用 | AI 生成失败等异步任务异常 |

### E. 帖子可见权限说明

| visibility | 含义 | 说明 |
|------------|------|------|
| 0 | 公开 | 所有用户可见 |
| 1 | 登录可见 | 仅已登录用户可见 |
| 2 | 粉丝可见 | 仅作者粉丝可见 |
| 3 | 私密 | 仅作者本人可见 |

**过滤规则**：
- 列表接口自动过滤不可见帖子
- 详情接口对不可见帖子返回 **404**（非 403），避免泄露存在信息
- 作者本人始终可查看自己的帖子
- 管理后台接口不过滤可见性
